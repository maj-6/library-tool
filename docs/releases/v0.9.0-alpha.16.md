# v0.9.0-alpha.16

Library Tool `0.9.0-alpha.16` releases alongside Library Tool Capture
`0.5.2-alpha.15` (`versionCode` 46). This prerelease keeps Corrections stable
through background work and makes a page-by-page digitization pass faster.

## Correct captures without losing your place

New image revisions now arrive invisibly in the mounted editor. **Queue
transform** stays available while Corrections refreshes, and drafts, tool
state, undo/redo history, focus, and the last confirmed image remain intact.
There is no longer a reload notice covering the primary action.

The Books pane also keeps its vertical position, each book's horizontal
capture position, and **Show more** expansion across operations, including
scrolling performed while an operation is still pending.

## Masks and cleanup are directly actionable

In Mask mode, the primary action is now **Apply mask**. It commits and submits
a valid outline in one step. Right-clicking an eligible capture now offers
**Delete capture image**, targeting that exact page without first navigating
away from an unrelated edit. The page remains recoverable in Info > Trash.

## Move through a book faster

A saved **Advance after transform** toggle moves to the next capture as soon
as a perspective transform is accepted. Failed or cancelled work remains
visible instead of silently advancing.

## Set aside books for digitization

Press **G** (or remap the command) to toggle the current book as a scan
candidate. The new **Scan candidates** Books view gathers those books for the
end-of-project harvest. The classification follows capture metadata to
Library Tool Capture, where Home and book details identify the candidate.

The Artifacts tree is also denser, with children visibly indented beneath
their groups.
