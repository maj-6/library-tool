# v0.9.0-alpha.7

Library Tool `0.9.0-alpha.7` is a desktop-only prerelease. Library Tool
Capture remains at `0.5.2-alpha.11`; Android's version identity is unchanged,
so this build does not replace its APK.

## Corrections opens ready to work

- The Corrections editor now follows the desktop application's shared
  appearance, control, focus, and navigation conventions.
- Manual, legacy, and capture-only records load through a bounded lazy index,
  avoiding archive and layout work before the list becomes usable.
- Capture thumbnails and safe previews appear as soon as they are available.
  Selecting a capture no longer waits for all of its regions and full-resolution
  details to finish loading.
- Large books keep the initial capture list bounded while retaining explicit
  keyboard-reachable access to the remaining captures.
- Closing the Corrections window no longer sends teardown work to an already
  destroyed Electron window.

## Cloud sync finishes large libraries

- Desktop capture sync now pages through the complete cloud queue instead of
  stopping after the first 50 books.
- Per-book failures retain their detailed HTTP and storage diagnostics while
  later books continue, and retry state remains visible.
- The sync display can be hidden when a run is slow or stuck and reopened
  without discarding the job's progress or errors.
- Private Supabase Storage downloads use the authenticated object route.
  Missing buckets and objects are reported distinctly instead of collapsing
  into an opaque HTTP 400/404.
- R2 destination validation and inventory preflight checks expose a missing or
  misconfigured bucket before a long transfer begins.

## Updating

Windows installs update in place from the previous prerelease. Stable installs
receive this build only when **Settings → Updates → include prerelease updates**
is enabled.
