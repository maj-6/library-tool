# Library Tool 0.9.0-alpha.18

Library Tool `0.9.0-alpha.18` releases alongside Library Tool Capture
`0.5.2-alpha.18` (`versionCode` 49). This prerelease makes the physical
digitization intake flow hands-free and moves match decisions into a
synchronized review queue.

## Capture evidence without interruptions

Physical-scan capture no longer asks for confirmation between photos or shows
a cover/title chooser. Say **cover** or **title** to photograph each piece of
evidence, take as many observations as needed, then say **A**, **B**, or **C**
to finish and route the session to one of three independently active scan
collections.

Every temporary image is read through hosted **Mistral OCR 4.1** and deleted.
The queue stores bounded OCR text and, for covers, a small non-reversible visual
signature rather than the photograph itself.

## Review confidence-rated matches later

Android and Library Tool Desktop synchronize each evidence session as one
deferred match proposal. Review shows the proposed existing book, confidence,
text evidence, visual corroboration, and ambiguity information before the
proposal is approved or rejected.

Approval atomically moves the exact proposed book into the selected scan
collection while retaining its capture collection as provenance. Concurrently
changed sessions or proposals are refreshed instead of applying a stale
decision.

## Corroborate covers across exposure changes

Cover matching combines title, author, year, and OCR evidence with normalized
color, structure, gradient, and aspect features. The visual comparison is
designed to tolerate ordinary exposure differences, while close candidates are
capped for manual review rather than receiving false certainty.

## Cloud compatibility

Migration `031_scan_search_deferred_review` adds session-aware queue state,
strict evidence validation, confidence and proposal metadata, owner-scoped row
security, and transactional propose/approve/reject RPCs. It has already been
applied to the configured cloud project.

## Updating

Install the desktop prerelease normally. Install the Android APK over the
existing Library Tool Capture app without uninstalling or clearing its data;
the same signing identity preserves the local capture and review queues.
