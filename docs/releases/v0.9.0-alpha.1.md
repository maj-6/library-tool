# v0.9.0-alpha.1

Library Tool `0.9.0-alpha.1` is a desktop-only prerelease for hands-on testing.
It works with the currently published Library Tool Capture `0.5.2-alpha.5`;
Android's version identity is unchanged, so this release does not rebuild the
APK.

## Highlights

- Corrections now treats captured and manually entered records as first-class
  items even when they cannot be opened as editor books. Their images,
  generated metadata, OCR, Mistral regions, notes, processed renditions, review
  state, image categories, region roles, and captions can all be browsed and
  edited from the Corrections manager.
- Perspective and Image Adjust work is durable. Editors can refine the
  detected quadrilateral, apply a remembered binary brightness adjustment,
  optionally request OCR, queue the job with Space, and safely close and
  reopen the window without losing accepted work. Concurrent windows converge
  without overwriting active drafts.
- Legacy capture archives gain bounded, dry-run-first, resumable `.lib/3`
  association backfill and explicit signed-in cloud publication. Missing or
  corrupt captures are isolated, and Android confirmation remains revision
  safe.
- Keyboard and accessibility behavior, large-book performance, cancellation
  and restart, duplicate submission, OCR failure, and `.lib/1` and `.lib/2`
  compatibility now have composed release gates.

## Deployment and known caveats

- Cloud migration `023_capture_lib_import_transition_guard.sql` must be applied
  before capture-confirmation publication is used with this build.
- Importing a non-empty `.lib/3` capture graph into an already-existing
  catalogue item remains refused until its raster and spatial persistence
  adapter is available.
- An image transform can succeed while its OCR follow-up reports a separate
  unavailable-provider failure; no production OCR follow-up provider is bound
  yet.
- Automated validation does not replace a clean-Windows installer smoke, a
  real Chromium and screen-reader pass, a physical Android device pass, or a
  live external OCR-provider check.
