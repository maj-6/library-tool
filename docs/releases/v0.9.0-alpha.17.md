# Library Tool 0.9.0-alpha.17

Library Tool `0.9.0-alpha.17` releases alongside Library Tool Capture
`0.5.2-alpha.17` (`versionCode` 48). This prerelease adds a synchronized
workflow for physically setting books aside for full-book digitization.

## Keep capture and digitization queues separate

Collections now have an immutable **capture** or **scan queue** purpose. Both
types retain normal hierarchy, tags, cloud sync, and browsing, while Android
keeps an active capture collection and active scan collection independently.

Marking a book for scanning moves its effective membership to the active scan
collection and records the capture collection it came from. That source remains
available as audit provenance even after later moves.

## Mark books wherever you encounter them

During Android capture, tap the scanner button or say **scan**. The book is
marked only when **Done** seals it, so cancelling cannot leave a ghost queue
entry. Sealed local books and Inspect selections expose the same action outside
the editor.

An active physical scan mark uses the existing scanner overlay and subtle
highlight in every Android book representation. An assigned 1-5 priority is
shown on the tag; an unprioritized marked book displays `?`.

## Match a photographed book to an existing record

From Inspect, photograph a cover or title page and choose the matching existing
book. Android reads the temporary image with **Mistral OCR 4.1**, adds only
bounded recognized text to an owner-scoped durable search queue, and deletes
the image. The queue never stores or uploads the photo itself.

Library Tool Desktop shows synchronized scan collections, active scan state,
and pending OCR searches, with ranked choices for completing a match. Queue
completion and the collection move commit together in the cloud.

## Cloud compatibility

Migration `029_scan_collection_workflow` adds immutable collection types,
owner-scoped scan state and OCR search rows, and atomic authenticated RPCs. Row
level security, explicit grants, bounded payloads, revision checks, and
same-type collection merges protect the workflow across Android and desktop.

## Updating

Install the Android APK over the existing Library Tool Capture app. Do not
uninstall the app or clear its data: Android preserves the local capture and
search queues only during an in-place, same-signing-key update.
