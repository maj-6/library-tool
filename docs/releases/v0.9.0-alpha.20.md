# Library Tool 0.9.0-alpha.20

Library Tool `0.9.0-alpha.20` releases alongside Library Tool Capture
`0.5.2-alpha.20` (`versionCode` 51). This prerelease adds copy-specific marked
prices and scan assessments, with portable backups and guarded review imports.

## Record copy-specific scan decisions

Desktop now keeps **Marked price** separate from the legacy price field and
supports the exact scan-priority values **n/s (no scan)**, **Low**, **Medium**,
and **High**. A missing value remains visibly **Unassessed**.

Priority controls expose the short verdict on hover and keyboard focus. Click,
touch, Enter, or Space opens the full book-associated reasoning in an
accessible popover with safe text rendering, error states, Escape/click-away
closing, and focus return.

## Keep reasoning private and verifiable

Full Markdown reasoning is stored under the mutable Desktop data root as a
bounded, hashed, versioned artifact. Reads verify identity, containment,
regular-file status, UTF-8, byte length, and SHA-256; writes use CAS,
idempotency keys, workspace leases, and recoverable transactions.

Manual entries, promoted captures, canonical builds, and checked-library rows
now have stable update paths. Checked-library curation uses a mutable sidecar;
the shipped catalogue remains read-only. Review-only metadata is excluded from
public catalogue publishing.

## Back up and import deliberately

Portable ZIP export/import preserves the three short fields, unknown metadata,
source evidence, and the associated reasoning artifact. Imports validate the
whole bundle before writing and surface CAS conflicts instead of overwriting.

The curated book-review importer is dry-run-first and selected-only. It
requires exact source references and hashes, a destination snapshot, and a new
pre-import backup before any commit. This release adds the importer but does
not import or modify the separate enrichment snapshot.

## Android compatibility

Android's unrelated numeric 1–5 scan rank now uses `scan_priority_rank`.
Readers accept a genuinely numeric legacy `scan_priority` during the
compatibility window, but textual Desktop assessments are never inferred as
numeric ranks.

## Updating

Install the desktop prerelease normally. Install the Android APK over the
existing Library Tool Capture app without uninstalling or clearing its data;
the unchanged signing identity preserves local capture and review queues.
