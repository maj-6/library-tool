# v0.9.0-alpha.14

Library Tool `0.9.0-alpha.14` is a desktop-only prerelease fixing one bug
cluster in `0.9.0-alpha.13`. Library Tool Capture's version identity is
unchanged, so this build does not replace its APK.

## Edits survive background refreshes

Corrections could vanish mid-edit: any background refresh — the editor's own
two-second convergence check, a review resolution, a finished transform —
tore down and rebuilt the whole editor, discarding an in-progress corner
drag, mask draft, or untried adjustments, and sometimes flashing
"Image unavailable — no safe renderable source" while doing it.

The editor now stays mounted through refreshes that change nothing it is
editing. Region updates land on the open editor in place. If a genuinely
newer revision of the open image arrives while there is unsaved work, the
editor keeps the work and shows a small "Newer revision available — Reload"
notice instead of discarding anything. The displayed image's data is never
released while it is still on screen, which removes the flash.

Verified on a full-size library: a corner drag survived twelve consecutive
background refresh cycles untouched, with no image flashes.
