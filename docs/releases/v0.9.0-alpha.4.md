# v0.9.0-alpha.4

Library Tool `0.9.0-alpha.4` is a desktop-only prerelease. Library Tool
Capture remains at `0.5.2-alpha.7`; Android's version identity is unchanged,
so this release does not rebuild the APK.

It answers the first piece of feedback on `0.9.0-alpha.3`: the Corrections
manager gained many per-item tools but no way to work through the synced
phone captures themselves.

## Working through phone captures

The Corrections book list now has three views: **All**, **Captures** — only
capture-backed items, newest import first — and **Attention** — items whose
review still needs a look. Each view shows its count, and the text filter
narrows within the active view.

Press **j** and **k** (or the arrow buttons above the list) to step the
selection through the current view without leaving the editor: fix a page,
press j, and the next capture is open. In the Attention view, resolving an
item and pressing j lands on the next one that still needs work, so the view
behaves as a review queue that empties as you go.

## Fixes

- Corrections made on captures imported before transport tracking existed
  now publish to the phone. Previously the publisher required a field that
  older imports lack, silently skipping them — on a long-lived archive that
  was most captures.

## Known caveats

- The caveats of `0.9.0-alpha.3` still apply (recent-captures reach on the
  phone, no page reorder/removal, desktop-local region labels, and the
  cloud migration prerequisite described in its notes).
