# v0.9.0-alpha.8

Library Tool `0.9.0-alpha.8` is a desktop-only prerelease. Library Tool
Capture remains at `0.5.2-alpha.11`; Android's version identity is unchanged,
so this build does not replace its APK.

## Cloud capture retries complete cleanly

- Verified captures left in the cloud `error` state by an earlier storage or
  transport failure can now be acknowledged atomically as imported.
- The acknowledgement keeps its revision and authorization checks, so voided,
  processing, changed, or unauthorized captures still fail closed.
- Definitive HTTP conflicts are no longer submitted twice. Ambiguous lost
  responses retain their safe, idempotent replay.

## Corrections captures appear progressively

- Capture cards and metadata paint immediately with stable placeholders instead
  of starting every thumbnail request at once.
- Thumbnails hydrate only near the Books pane's scrolling viewport, while the
  selected capture, keyboard focus, and pointer focus receive immediate
  priority.
- The authoritative selected image starts before its thumbnail, keeping clicks
  responsive even in large libraries.
- Loading placeholders remain until the browser confirms the image is ready;
  failed previews show an explicit **Image unavailable** state instead of a
  blank or broken tile.

## Updating

Windows installs update in place from the previous prerelease. Stable installs
receive this build only when **Settings → Updates → include prerelease updates**
is enabled.
