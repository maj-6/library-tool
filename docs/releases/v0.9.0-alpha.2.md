# v0.9.0-alpha.2

Library Tool `0.9.0-alpha.2` is a desktop-only hotfix prerelease. Library
Tool Capture remains at `0.5.2-alpha.5`; Android's version identity is
unchanged, so this release does not rebuild the APK.

## Fixes

- Provider, network, OCR, and import exceptions raised while a protected
  credential lease was active were incorrectly reported as "protected
  credential storage is unavailable." The original error is now preserved so
  the actual sync or provider failure can be diagnosed.
- Credential leases still remain active for the full protected operation, and
  credential ownership and lifetime checks are unchanged. This hotfix requires
  no credential-vault reset or migration.
- The frozen Windows sidecar release smoke now validates protected-store
  health, protected credential write, persistence across a sidecar restart,
  and credential clear.

## Known caveat

- This release fixes misleading error reporting; it does not suppress the
  underlying provider or transport failure. A real upstream failure may still
  require retrying the operation after its cause is resolved.
