# v0.9.0-alpha.5

Library Tool `0.9.0-alpha.5` is a desktop-only prerelease. Library Tool
Capture remains at `0.5.2-alpha.9`; Android's version identity is unchanged,
so this release does not rebuild the APK.

## Capture import reliability

- Importing a capture now tolerates one brief asset-directory update while
  the phone sync finishes publishing the capture's files. Previously that
  harmless overlap could stop the import with `the capture asset directory
  changed while it was listed`.
- Capture import still fails closed when the directory is replaced, redirected,
  unavailable, or keeps changing. The retry is limited to one complete,
  identity-pinned re-listing, so it cannot mix files from different capture
  directories or archive an unstable generation.

## Known caveats

- The caveats of `0.9.0-alpha.4` still apply (recent-captures reach on the
  phone, no page reorder/removal, desktop-local region labels, and the cloud
  migration prerequisite described in the earlier notes).
