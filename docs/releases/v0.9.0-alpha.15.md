# v0.9.0-alpha.15

Library Tool `0.9.0-alpha.15` releases alongside Library Tool Capture
`0.5.2-alpha.14` (`versionCode` 45). This prerelease makes rapid figure
extraction and recoverable capture cleanup work as one continuous workflow.

## Extract figures without leaving the capture

Pressing **X** over a detected region now creates one labelled extracted
figure while the source capture remains open. The source region gains a
persistent dashed marker whose preview does not replace the editor, and repeat
extractions remain visible. A committed free-form mask follows the same path:
its exact geometry is retained for the marker while OCR runs privately against
the crop.

The extraction boundary now verifies the selected region or mask against the
crop geometry, so a stale or mismatched command cannot attach the wrong image
to a marker.

## Remove a capture and keep moving

With a capture selected, **Backspace** sends it to Info → Trash and advances
to the next capture, or the previous one at the end of a book. Typing fields,
dialogs, mask drafts, gestures, unsaved edits, and in-flight extraction remain
protected from the shortcut. Other Corrections windows converge without
restoring a removed selection or overwriting newer navigation.

Trash restores the same stable capture identity, original order, camera
image, corrected display, OCR data, and correction history. Interior removals
do not renumber the pages around them.

## Desktop and phone agree on removed pages

Page removal and restoration now sync explicitly to Library Tool Capture.
The phone hides a removed page while retaining its exact bytes and history,
then reveals that same page after a restore. Lifecycle updates arrive before
pixel corrections, are fetched completely for large batches, and reject stale
or conflicting revisions. Work queued before a removal can no longer revive
or mutate the hidden page.
