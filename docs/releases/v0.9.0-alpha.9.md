# v0.9.0-alpha.9

Library Tool `0.9.0-alpha.9` is a desktop-only prerelease. Library Tool
Capture remains at `0.5.2-alpha.12`; Android's version identity is unchanged,
so this build does not replace its APK.

## The Corrections editor is usable on a real library

Opening a book took over ten seconds per request on a thousand-capture
library, every time, and the editor's own two-second poll kept the sidecar
rebuilding its index while a reviewer worked. Measured on the live
983-capture / 1008-book library:

- per-item editor request — 10.5–12.4s → 0.04s
- the index endpoint — 6.6s → 2.1s warm, and a reviewer's first open 6.6s → 1.85s

The snapshot was hashing two gigabytes of archives to read two fields, and
the poll now asks a cheap probe whether anything changed instead of
rebuilding. The index is also served in tiers, so the books list arrives
without waiting on per-capture detail.

## Masks and processing presets

- An optional polygon mask clears everything outside the shape a reviewer
  draws: transparent in the corrected display, white in the OCR-ready
  rendition, preserved in the thumbnail. The mask travels through the same
  perspective transform as the quad, so it lands where it was drawn.
- New processing operations — unsharp mask, kernel sharpen, gamma, contrast,
  per-channel gains, and white balance in gray-world or manual
  temperature/tint modes — can be saved as named presets and reapplied.
- Renders without a mask are byte-identical to the previous build.

## Region boxes work as expected

- The editor opens in **Select**, so region boxes are no longer hover- and
  click-dead until the tool switcher is found.
- The item-metadata form no longer paints near-black text on near-black
  fields under the sage theme.
- `x` extracts the hovered box as its own artifact — cropped to the region's
  padded bounding quad, with re-OCR queued — without touching the source.
- `v` archives an image out of the capture's working set; it stays linked for
  audit behind a quiet reveal row, and the same key or undo restores it.
  (Archive previously bound `a`, which the image editor already used to enter
  Image Adjust; whichever fired depended on where focus sat.)

## Phone OCR geometry survives desktop import

Word and block boxes produced by the phone's Mistral pass are now carried
across capture import through remap records pinned to the displayed image, so
a book imported from Library Tool Capture opens with its overlay in place.
A backfill tool pins the existing captures. The overlay and the remap also
stopped re-applying EXIF orientation to coordinates that capture geometry
already records as upright.

## Groundwork and robustness

- A multi-engine OCR foundation lands: a provider registry with Mistral, AWS
  Textract Layout, and Datalab adapters emitting one normalized result, plus a
  folder queue for arbitrary external models. It is not yet wired into the
  re-OCR routes or the UI.
- One malformed external OCR result no longer wedges the queue behind it —
  bad jobs are quarantined with a diagnostic and their neighbours still
  collect.

## Updating

Windows installs update in place from the previous prerelease. Stable installs
receive this build only when **Settings → Updates → include prerelease updates**
is enabled.
