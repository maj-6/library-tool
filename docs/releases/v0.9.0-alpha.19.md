# Library Tool 0.9.0-alpha.19

Library Tool `0.9.0-alpha.19` releases alongside Library Tool Capture
`0.5.2-alpha.19` (`versionCode` 50). This prerelease makes physical-scan intake
immediate and gives Android a dedicated synchronized queue inspector.

## Inspect the physical scan queue on Android

Android's Home navigation is now icon-only, leaving room for a Physical Scan
Queue tab. The inspector groups observations by capture session and shows
processing state, destination scan collection, confidence, evidence, and the
available review, resume, or dismiss action.

The launcher and navigation icon plate use a lighter neutral sage instead of
the previous botanical green.

## Keep capturing without interruptions

With exactly one active scan collection, saying **cover** or **title** takes the
photo and routes it immediately—there is no confirmation screen. The cover and
title capture view stays active afterward so the next book can be photographed
without returning to Inspect. A/B/C voice routing remains available when two or
three scan collections are active.

## Queue first, process in the background

Android creates and synchronizes a queue placeholder as soon as a photo is
routed. Hosted **Mistral OCR 4.1** fills the same item later; no on-device OCR is
used. Processing and permanent cloud-sync failures produce durable
notifications that open the queue inspector.

Temporary photos remain in app-private storage only until hosted processing
finishes. Covers retain a bounded, non-reversible visual signature for
exposure-tolerant color and feature corroboration; the photo itself is deleted.

## Cloud and desktop compatibility

Migrations `032_scan_search_processing_queue` and
`033_scan_search_queue_cas_hardening` are applied to the configured cloud
project. They add the monotonic placeholder-to-evidence transition, block match
proposals while any observation is incomplete, and protect owner-scoped failure
cleanup with revision and blank-evidence compare-and-swap checks. Desktop waits
for complete evidence before proposing a match and presents failed processing
ahead of stale candidates.

## Updating

Install the desktop prerelease normally. Install the Android APK over the
existing Library Tool Capture app without uninstalling or clearing its data;
the unchanged signing identity preserves the local capture and review queues.
