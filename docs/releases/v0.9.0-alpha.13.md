# v0.9.0-alpha.13

Library Tool `0.9.0-alpha.13` releases alongside Library Tool Capture
`0.5.2-alpha.13` (`versionCode` 44). Both halves change together so the
corrected capture selected on the desktop is the same page the phone installs.

## Corrected captures update in place

Applying a transform now refreshes the selected capture itself instead of
leaving the editor on an older display or a separate processed artifact.
Selection and navigation stay put, repeat edits build on the latest corrected
pixels, and the result remains current after reopening the app. Transforms
started from either Display or Original converge on the same logical display.

## Original camera images are safeguarded

Before the first correction replaces a capture display, the desktop verifies
and stores the camera original in a private backup. Backed captures gain
**View original** and **Restore original** controls in the image editor.

Restoring replaces the corrected display while retaining both correction
history and the verified backup. Routine browsing and indexing do not read the
cold backup, so protecting originals does not put them back on the editor's
hot path.

Restore is local: it prevents that desktop from publishing the restored
correction again, but it does not retract a correction already uploaded.

## Desktop and phone converge reliably

Cloud publication now follows the exact correction currently active on the
desktop. Library Tool Capture verifies that result against the immutable camera
original, installs it on the next Home resume or explicit sync, and re-runs OCR
against the corrected pixels.

Incomplete cloud rows and missing or damaged installed displays can repair
themselves. Overlapping background and explicit syncs also refuse to replace a
newer correction with an older download. The phone's capture list now shows
desktop-curated title, author, and year when available, falling back field by
field to its own extracted text.

Corrections remain poll-driven and apply only to captures still in the phone's
recent queue; archived or deleted entries are unchanged.

## Region labels can be hidden

A new **Region labels** button hides the text badges without hiding region
outlines or disabling their interactions. The preference is saved with the
Corrections profile and follows other open Corrections windows.
