# v0.9.0-alpha.11

Library Tool `0.9.0-alpha.11` is a desktop-only prerelease fixing one bug in
`0.9.0-alpha.10`. Library Tool Capture remains at `0.5.2-alpha.12`; Android's
version identity is unchanged, so this build does not replace its APK.

## The Corrections editor stays responsive after a transform

On `0.9.0-alpha.10`, applying a perspective transformation could freeze the
editor: the queue button stayed disabled and the corrected image never
appeared. Loading books also still took minutes on a large library even after
the previous build's loading fix.

Both had one cause. Every write the app makes leaves a small transaction
journal behind, and those journals were kept forever — a real library
accumulated over a thousand in three weeks. Every read of the corrections
workspace re-checked all of them, once per book, so one index build did
roughly a million file opens. Measured on a copy of the affected library, the
index took 236 seconds; applying a transform triggered a rebuild that held
the workspace busy for another four minutes, which is why the editor looked
frozen rather than merely slow.

Finished journals are now removed as soon as their work commits, and the app
sweeps any accumulated pile the first time it starts. The same index build
measures 4.3 seconds after the fix, and existing libraries clean themselves
on first launch — no manual steps.

Interrupted work keeps its journal until the next start, so crash recovery
is unchanged.
